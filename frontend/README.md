# رحلة التغيير — Frontend

واجهة تطبيق رحلة التغيير مبنية باستخدام Next.js App Router وReact وTypeScript.

## التشغيل المحلي

```bash
npm install
npm run dev
```

ثم افتح `http://localhost:3000`.

## فحوص الجودة

```bash
npm run lint
npm run build
```

توجد سكربتات تدقيق إضافية داخل `scripts/` لاختبار المسارات والمقاسات وعمليات الإدارة. تحتاج سكربتات المتصفح إلى Chrome يعمل بمنفذ CDP رقم `9222` وإلى خادم التطوير المحلي.

## بنية المصدر

- `src/app`: المسارات والصفحات وحالات التحميل والخطأ.
- `src/components/features`: واجهات المشارك والمشرف والمصادقة.
- `src/components/layout`: هيكل التطبيق والتنقل.
- `src/components/ui`: المكونات البصرية المشتركة.
- `src/state`: حالة العرض المحلية المؤقتة لحين ربط الباك إند.
- `src/mocks`: بيانات التطوير التجريبية.
